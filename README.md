# 🚀 JavaScript Fundamentals

A practical guide to learning and mastering the **core concepts of JavaScript** — from variables and data types to functions, classes, and TypeScript comparison.

---

## 📘 Overview

This repository is designed for beginners and anyone who wants to review JavaScript fundamentals.  
Each topic includes:
- Short explanations  
- Commented examples  
- Practice exercises  
- Optional challenges  

---

## 🧩 Topics Covered

1. **Variables and Constants (`let`, `const`)** – Scope and hoisting  
2. **Data Types** – Primitive and reference types  
3. **Concatenation & Template Literals** – String handling and type coercion  
4. **Objects & Arrays** – Creation, manipulation, iteration  
5. **Comparison Operators** – `==`, `===`, `!=`, `<`, `>`, etc.  
6. **Logical Operators** – `&&`, `||`, `!`, short-circuit behavior  
7. **Conditional Statements** – `if`, `else`, `switch`  
8. **Loops** – `for`, `while`, `do...while`, `for...of`, `for...in`  
9. **Functions** – Declarations, arrow functions, parameters  
10. **Classes & Methods** – ES6 classes, constructors, inheritance  
11. **TypeScript vs JavaScript** – Main differences and when to use each
